# TerraCivilization SimpleGameplay G4 基础二吃一设计稿

> 本稿承接 G3：当前已经支持选中棋子、普通行走、跳跃、骑兵特殊跳跃、跳跃连跳、回合开始棋子底色、HISM tile 高亮。
>
> G4 目标是在玩家预览下一步落点时，提示该步会吃掉哪些敌方棋子，并在行动结束时结算基础二吃一。

---

## 1. G4 目标

本阶段新增：

1. **落点可吃子预览**
   - 选中棋子后，仍按 G3 显示所有可行走 / 可跳跃落点。
   - 对每一个下一步落点，临时假设选中棋子走到该落点。
   - 如果该假设局面中能形成基础二吃一，则把这一步所有可吃的敌方棋子所在 Cell 用深红色高亮。
   - 同一个敌方棋子可能被多个落点吃到；只要至少有一个当前可见落点能吃它，就显示深红。

2. **hover 落点时加深对应可吃目标**
   - 当鼠标 hover 到某个可行走 / 可跳跃落点时：
     - 该落点本身仍沿用 G3 的淡蓝加深规则。
     - 只有“走到这个落点会吃掉的敌方棋子”从深红色加深为更亮 / 更深的红色。
   - 其他落点可吃但不属于当前 hover 落点的敌方棋子保持普通深红色。

3. **行动执行后的吃子结算时机**
   - 如果玩家点击的是一个带有可吃目标的普通行走落点：
     - 棋子移动到该落点。
     - 本次行动进入“只能结束回合”的状态。
     - 被吃目标继续用深红色标出，等待玩家点击自身结束回合。
   - 如果玩家点击的是一个带有可吃目标的跳跃落点：
     - 棋子跳跃到该落点。
     - 该落点当前可吃目标继续用深红色标出。
     - 如果该棋子仍有下一跳，则玩家可以继续跳跃；不是必须立刻吃子并结束。
     - 如果玩家继续跳跃，待结算吃子会改为新落点对应的可吃目标。
   - 如果玩家点击的落点没有可吃目标：
     - 普通行走仍进入 G3 的只能结束回合。
     - 跳跃仍进入 G3 的可继续跳跃。

4. **结束回合时结算吃子**
   - 玩家点击自身所在 Cell 结束回合时，按该棋子最终所在 Cell 重新计算并移除当前节点可吃目标。
   - 被吃棋子的 `bAlive=false`，其所在 `CellToPieceId` 清空。
   - 本阶段只处理吃子移除，不处理主将失败、阵营淘汰、胜负闭环；这些留给 G6。

## 2. 本阶段只实现基础二吃一

G4 只实现基础阵型：

```text
A A B
```

其中：

- 两个 `A` 必须属于当前行动阵营。
- `B` 必须是敌方仍存活棋子。
- 三者位于同一条方向射线。
- 可以吃掉 `B`。

暂不实现：

- 弓兵远程 `A' A - B`。
- 山脉弓兵 `A' A - - B`。
- 森林防远程。
- 主将被吃后的阵营失败。
- 连锁吃子。

---

## 3. “由这一步形成”的简化判定

为了满足“若走到这一步能实现吃子”的预览语义，G4 对每个候选落点执行一次临时落子判定：

```text
ActionPiece 从当前 Cell 临时移动到 CandidateTargetCell
  -> 只扫描与 ActionPiece 相关的基础二吃一
  -> 得到该落点会吃掉的敌方棋子集合
```

扫描两类阵型：

### 3.1 行动棋子作为真正攻击者

```text
ActionPiece(A)  Friendly(A)  Enemy(B)
```

从行动棋子所在 Cell 沿各方向向前：

1. 第 1 格必须是本方棋子。
2. 第 2 格必须是敌方棋子。
3. 第 2 格敌方棋子加入可吃目标。

### 3.2 行动棋子作为先锋

```text
Friendly(A)  ActionPiece(A)  Enemy(B)
```

从行动棋子所在 Cell 沿各方向同时检查反向一侧与正向一侧：

1. 某一方向第 1 格是敌方棋子。
2. 相反方向第 1 格是本方棋子。
3. 该敌方棋子加入可吃目标。

实现上为了复用球面 Hex/Pent 的分叉直线定义，`ActionPiece` 作为先锋时可以枚举相邻的本方棋子作为 `Prev`，再调用 `StepForwardBranches_(Prev, ActionCell)` 找到 `Enemy` 方向候选。

---

## 4. 五边形分叉直线

G4 继续复用 G3 的 `StepForwardBranches_`：

- 当前 Cell 是六边形：沿对向邻居唯一前进。
- 当前 Cell 是五边形：沿两个对向候选分叉前进。

因此基础二吃一在五边形附近也支持分叉：

- 如果任意分叉方向形成 `A A B`，则 `B` 是可吃目标。
- 同一个 `B` 被多个分叉命中时只记录一次。

## 5. Gameplay 容器新增数据

`FTerraGameplayContainer` 新增：

```cpp
TMap<int32, TSet<int32>> ActionTargetCellIdToCaptureCellIds;
TSet<int32> PendingCapturePieceIds;
TSet<int32> PendingCaptureCellIds;
```

含义：

| 字段 | 含义 |
| --- | --- |
| `ActionTargetCellIdToCaptureCellIds` | 当前可见下一步落点 -> 假设走到该落点可吃的敌方 Cell 集合 |
| `PendingCapturePieceIds` | 当前节点如果点击自身结束回合，则会结算的敌方棋子 ID；连跳到新节点后会重建 |
| `PendingCaptureCellIds` | 同上，缓存 CellId 便于高亮和刷新 |

新增只读接口：

```cpp
bool IsCapturePreviewCellForActionTarget(int32 CaptureCellId, int32 ActionTargetCellId) const;
bool CollectCapturePreviewCellIdsForActionTarget(int32 ActionTargetCellId, TArray<int32>& OutCellIds) const;
```

用途：

- 渲染桥在写某个 Cell 的最终颜色时，判断该 Cell 是否是当前 hover 落点对应的可吃目标。
- hover 落点变化时，渲染桥能刷新旧 / 新 hover 落点关联的可吃目标。

## 6. 高亮颜色与优先级

G4 新增颜色：

| 来源 | 颜色 |
| --- | --- |
| 可吃目标预览 / 待结算可吃目标 | 深红色 `(0.65, 0.02, 0.02)` |
| hover 某落点时，该落点对应可吃目标 | 加深红色 `(1.0, 0.0, 0.0)` |

优先级：

| 优先级 | 来源 |
| --- | --- |
| 650 | G4 hover 落点对应可吃目标加深红 |
| 600 | G4 可吃目标预览 / 待结算可吃目标深红 |
| 450 | G3 可行走 / 可跳跃落点 hover 深淡蓝 |
| 400 | G2 行走后可停下蓝色 |
| 350 | G2/G3 选中棋子脚下黄色 |
| 300 | G3 可行走 / 可跳跃落点淡蓝 |
| 200 | G2.5 hover 当前阵营棋子红粉 |
| 150 | G2.5 当前阵营棋子淡粉 |
| 100 | 普通 hover |

实现方式：

- `GameplayHighlights` 写入普通深红色。
- 渲染桥在 `WriteHISMHighlightForCell_` 中判断：
  - 如果当前 Cell 是 `HISMCurrentHoverCellId` 对应落点的可吃目标，则使用加深红色覆盖深红。

## 7. 交互状态

G4 不新增公开交互阶段，复用现有阶段：

| 情况 | 阶段 |
| --- | --- |
| 点击无吃子的普通行走落点 | `PieceMovedCanEndTurn` |
| 点击无吃子的跳跃落点 | `PieceJumpingCanContinue` |
| 点击有吃子的普通行走落点 | `PieceMovedCanEndTurn` |
| 点击有吃子的跳跃落点 | `PieceJumpingCanContinue` |

关键规则：

- `PendingCapturePieceIds` 非空表示当前节点如果点击自身结束回合，会有待结算吃子。
- 普通行走后只能点击自身结束回合。
- 跳跃后即使当前节点可吃子，也仍可继续点击下一跳落点；继续跳跃后会用新节点的吃子结果覆盖旧节点。
- 结束回合时按最终所在 Cell 重新计算并移除 `PendingCapturePieceIds`，再推进回合。

## 8. 验收清单

### 8.1 预览

- 选择本方可移动棋子后，所有 G3 落点仍显示淡蓝色。
- 如果某个淡蓝落点会形成基础 `A A B`，对应敌方棋子显示深红色。
- 多个落点能吃同一敌方棋子时，该棋子只显示一份深红色。

### 8.2 Hover

- hover 到普通无吃子落点时，只加深该淡蓝落点。
- hover 到有吃子的落点时：
  - 该落点淡蓝加深。
  - 该落点能吃的敌方棋子从深红变为加深红。
  - 其他落点关联的可吃目标保持深红。

### 8.3 执行

- 点击有吃子的普通行走落点后，棋子移动到落点，不能继续移动。
- 点击有吃子的跳跃落点后，棋子跳到落点；如果仍有合法下一跳，可以继续跳跃。
- 跳跃后当前节点待吃目标保持深红提示。
- 继续跳跃到新节点后，待吃目标更新为新节点对应的可吃目标。
- 点击自身 Cell 后，最终节点的待吃目标从棋盘移除，回合切到下一个玩家。

### 8.4 非吃子 G3 行为保持

- 点击无吃子的普通行走落点后仍只能结束回合。
- 点击无吃子的跳跃落点后仍可继续跳跃。
- 连跳时仍不能原路反跳。

---

## 9. 暂不处理

- 弓兵远程吃子。
- 山脉弓兵加成。
- 森林防远程。
- 主将失败与阵营淘汰。
- 胜利判定。
- 被吃棋子的动画或延迟表现。
